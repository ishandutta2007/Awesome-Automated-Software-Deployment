## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Jenkins](https://github.com/jenkinsci/jenkins)** [![Stars](https://img.shields.io/github/stars/jenkinsci/jenkins?style=social&color=white)](https://github.com/jenkinsci/jenkins/stargazers)  
  **The most widely adopted automation server**, MIT licensed. **25,184 stars** 🌟. 1,800+ plugins for build, deploy, and automate. Pipeline-as-code with declarative and scripted syntax. Self-hosted, highly extensible, and battle-tested for enterprise deployments. 🏛️

- **[Dagger](https://github.com/dagger/dagger)** [![Stars](https://img.shields.io/github/stars/dagger/dagger?style=social&color=white)](https://github.com/dagger/dagger/stargazers)  
  **Programmable CI/CD engine with container-native pipelines**, Apache-2.0 licensed. **13,775 stars** 🌟. Write deployment pipelines in Go, Python, TypeScript, or GraphQL. Runs anywhere — locally, in CI, or in Kubernetes. Composable workflows for AI agents and continuous delivery. 🗡️

- **[Argo CD](https://github.com/argoproj/argo-cd)** [![Stars](https://img.shields.io/github/stars/argoproj/argo-cd?style=social&color=white)](https://github.com/argoproj/argo-cd/stargazers)  
  **Declarative GitOps continuous delivery engine for Kubernetes**, Apache-2.0 licensed. **12,466 stars** 🌟. Automatically syncs Kubernetes cluster state with Git repos. Supports Helm, Kustomize, and plain YAML manifests. The CNCF graduated standard for Kubernetes GitOps. 🎯

- **[Coolify](https://github.com/coollabsio/coolify)** [![Stars](https://img.shields.io/github/stars/coollabsio/coolify?style=social&color=white)](https://github.com/coollabsio/coolify/stargazers)  
  **An open-source & self-hostable Heroku / Netlify / Vercel alternative**, Apache-2.0 licensed. **11,850 stars** 🌟. Self-host your applications, databases, or static services on your own servers with automated git push deployments. 🚀

- **[Flux CD](https://github.com/fluxcd/flux2)** [![Stars](https://img.shields.io/github/stars/fluxcd/flux2?style=social&color=white)](https://github.com/fluxcd/flux2/stargazers)  
  **Open and extensible continuous delivery toolkit for Kubernetes**, Apache-2.0 licensed. **7,888 stars** 🌟. Modular GitOps controllers for source management, Kustomize, Helm releases, and automatic image updates. CNCF graduated project. 🦊

- **[GoCD](https://github.com/gocd/gocd)** [![Stars](https://img.shields.io/github/stars/gocd/gocd?style=social&color=white)](https://github.com/gocd/gocd/stargazers)  
  **Continuous delivery server by ThoughtWorks**, Apache-2.0 licensed. **7,114 stars** 🌟. End-to-end value stream mapping, parallel execution, dependency tracking, and complex release pipeline automation. 🗺️

- **[Spinnaker](https://github.com/spinnaker/spinnaker)** [![Stars](https://img.shields.io/github/stars/spinnaker/spinnaker?style=social&color=white)](https://github.com/spinnaker/spinnaker/stargazers)  
  **Multi-cloud continuous delivery platform**, Apache-2.0 licensed. **6,820 stars** 🌟. Used by Netflix, Google, and Airbnb. Automated canary analysis, blue/green deployments, and multi-cloud release orchestration. 🏗️

- **[CapRover](https://github.com/caprover/caprover)** [![Stars](https://img.shields.io/github/stars/caprover/caprover?style=social&color=white)](https://github.com/caprover/caprover/stargazers)  
  **Extremely easy App/Database deployment & web server manager**, Apache-2.0 licensed. **5,940 stars** 🌟. One-click automated deployments for NodeJS, Python, PHP, Java, Ruby, MySQL, MongoDB, and Postgres apps. 🚤

- **[Jenkins X](https://github.com/jenkins-x/jx)** [![Stars](https://img.shields.io/github/stars/jenkins-x/jx?style=social&color=white)](https://github.com/jenkins-x/jx/stargazers)  
  **Cloud-native automated CI/CD for Kubernetes**, Apache-2.0 licensed. **4,691 stars** 🌟. Automated preview environments on pull requests using GitOps, Tekton, and Prow. ☁️

- **[Tekton Pipelines](https://github.com/tektoncd/pipeline)** [![Stars](https://img.shields.io/github/stars/tektoncd/pipeline?style=social&color=white)](https://github.com/tektoncd/pipeline/stargazers)  
  **Kubernetes-native continuous delivery framework**, Apache-2.0 licensed. **3,850 stars** 🌟. Standardized building blocks for cloud-native deployment automation. CNCF incubating project. 🔧

- **[Concourse](https://github.com/concourse/concourse)** [![Stars](https://img.shields.io/github/stars/concourse/concourse?style=social&color=white)](https://github.com/concourse/concourse/stargazers)  
  **Container-based continuous automation system**, Apache-2.0 licensed. **3,420 stars** 🌟. Written in Go. Declarative pipelines focusing on idempotency, container isolation, and stateless build workers. 🏭

- **[Keep](https://github.com/keephq/keep)** [![Stars](https://img.shields.io/github/stars/keephq/keep?style=social&color=white)](https://github.com/keephq/keep/stargazers)  
  **Open-source alert management and deployment remediation platform**, MIT licensed. **3,150 stars** 🌟. Automated alert handling, incident response workflows, and deployment health checks. 🔔

- **[Armory Continuous Deployment](https://github.com/marketplace/actions/armory-continuous-deployment-as-a-service)** [![Stars](https://img.shields.io/github/stars/armory/armory?style=social&color=white)](https://github.com/marketplace/actions/armory-continuous-deployment-as-a-service)  
  **Enterprise Spinnaker action distribution**, Usage-based pricing. **850 stars** 🌟. Automated deployment strategies, progressive delivery, and canary analysis. 🛡️

Contributions are welcome! Follow these steps to submit new software deployment platforms or open-source CD tools:

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining table/list structure and formatting.
3. 🔗 Include project title, official website/GitHub link, exact Stars_Count badge, license, and brief description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your changes.
